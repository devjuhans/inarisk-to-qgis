# InaRISK to QGIS

A powerful and automated QGIS plugin to directly fetch, clip, and process InaRISK hazard, risk, and vulnerability data from the official BNPB ArcGIS ImageServers. Built to seamlessly integrate Indonesian disaster spatial data into your GIS workflows.

![InaRISK to QGIS](inarisktoqgis.png)

## Features

- **Direct BNPB Server Access**: Fetches data directly from the official BNPB InaRISK ImageServers without manual downloading.
- **Batch Processing**: Download all available disaster data types (Banjir, Gempa Bumi, Tsunami, dll) for your Area of Interest (AOI) in a single click.
- **Smart Reprojection**: Automatically handles CRS differences by reprojecting your AOI to match the server coordinate system (EPSG:4326) on the fly.
- **On-the-Fly Processing**: Includes built-in raster-to-vector polygon conversion, raster classification (Tinggi, Sedang, Rendah), and polygon smoothing.
- **Automatic Attributes**: Appends standardized source attribution, values, and hazard class categories natively to the generated layers.
- **Processing Summary Log**: Easily track the success, failure, or absence of data for each requested disaster type through an automated end-of-process summary log.

## Installation

### Option 1: Install via ZIP
1. Download this repository as a ZIP file (Click `Code` -> `Download ZIP`).
2. Open QGIS.
3. Go to **Plugins** -> **Manage and Install Plugins...**
4. Select the **Install from ZIP** tab on the left.
5. Select the downloaded ZIP file and click **Install Plugin**.

### Option 2: Manual Installation
Extract the repository folder into your QGIS active python plugin directory:
- **Windows**: `C:\Users\YOUR_USERNAME\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\`
- **Linux**: `~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/`
- **Mac OS**: `~/Library/Application Support/QGIS/QGIS3/profiles/default/python/plugins/`

Restart QGIS after extraction.

## How to Use

1. Click on the **InaRISK to QGIS** icon in your QGIS toolbar to launch the plugin.
2. **Index Options**:
   - **Index Type**: Choose the dataset category: *Bahaya* (Hazard), *Risiko* (Risk), or *Kerentanan* (Vulnerability).
   - **Disaster**: Select a specific disaster (e.g., Banjir, Tanah Longsor, Tsunami). Alternatively, check the **Download all types** box to run a batch download for all disasters under the selected index.
3. **Area Selection (AOI)**: 
   - Select an active vector layer from your QGIS project via the dropdown to define your study area extent.
   - Alternatively, click **Browse** to load an external spatial file (Shapefile, GeoJSON, etc.). The tool will strictly crop the data to this bounding box.
4. **Output Options**:
   - **Output Type**: Choose to output the raw continuous Raster, or have the plugin automatically convert it into discrete Vector Polygons.
   - **Format**: Select your preferred save format (`.gpkg`, `.shp`, `.geojson`, `.tif`, etc.).
   - **Classification**: Choose to automatically classify raw float values (0-1) into standardized ranges (Tinggi, Sedang, Rendah).
   - **Smooth Polygons**: If generating vector polygons, this optional setting smooths out the pixelated edges from the raster conversion.
   - **Save Folder**: Provide a directory path to save the files permanently. Leave it as `[Create temporary layer]` to generate temporary memory layers instead.
5. Click **Run**. The plugin will switch to the **Log** tab, showing you the real-time download progress and a clean process summary once completed.

### Output Attributes
Vector polygon outputs generated by this plugin will automatically be populated with the following attributes:
- `Kelas`: The hazard classification (e.g., "Indeks Bahaya Banjir Tinggi").
- `Value`: The specific numeric range of the class (e.g., "0.6 - 1.0").
- `Source`: Data attribution citing BNPB InaRISK.
